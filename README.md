# 💡 منصة فكرة (Fikra) - المجلس الأعلى للقضاء بدولة قطر
### Supreme Judiciary Council of Qatar - Institutional Innovation System

---

## 📌 نبذة عن المنظومة / Overview
**منصة فكرة (Fikra)** هي منظومة رقمية متكاملة لجمع وإدارة وتطوير المقترحات والأفكار الابتكارية لمنسوبي **المجلس الأعلى للقضاء (SJC)** في دولة قطر.
تم تصميم المنظومة بالهوية البصرية الرسمية للمجلس (اللون العنابي القطري `#8A1538` والذهبي الملكي `#C5A059`)، وتعتمد على خوارزميات **الذكاء الاصطناعي الفوري** للبحث في تشابه الأفكار، والتصنيف الآلي، وتوليد الوسوم، والمدخلات الصوتية، ولجنة التحكيم القضائي، ولوحة تحليلات تفاعلية، ولوحة إدارة المشرف.

---

## ✨ المميزات الرئيسية / Key Features

1. **الهوية البصرية للمجلس الأعلى للقضاء (SJC Qatar)**:
   - تصميم متطور، ألوان عنابية وذهبية فاخرة، خطوط عربية حديثة (`Cairo` & `Tajawal`).
   - دعم كامل للغتين العربية (الافتراضية) والإنجليزية مع التحويل الفوري بين RTL و LTR.
   - متوافقة تماماً مع أجهزة الجوال، الأجهزة اللوحية، والحواسيب المكتبية.

2. **تسجيل الدخول وإدارة المستخدمين (Authentication & RBAC)**:
   - تسجيل دخول وإنشاء حساب جديد باختيار الإدارة والمسمى الوظيفي من القوائم الرسمية للهيكل التنظيمي للمجلس.
   - التحقق من معايير كلمة المرور القوية (8 خانات، حروف كبيرة وصغيرة، أرقام، ورموز خاصة).
   - استعادة كلمة المرور عبر البريد الإلكتروني وتغيير كلمة المرور من الملف الشخصي.
   - أدوار وصلاحيات متعددة:
     - **موظف مبتكر (Employee)**: تقديم الأفكار، التصويت، التعليقات، متابعة الحالة.
     - **عضو لجنة التقييم (Committee Member)**: بوابة تحكيم، تقييم المعايير (الجدوى، الأثر، التكلفة، الابتكار) واعتماد أو رفض الأفكار.
     - **مدير النظام (Admin)**: إضافة وتعديل الإدارات، المسميات الوظيفية، ومجالات الابتكار.
   - مبدل أدوار سريع في الشريط العلوي لتجربة كافة الأدوار بسهولة.

3. **التقديم الذكي للأفكار والذكاء الاصطناعي (AI Similarity & Voice)**:
   - **بحث تشابه لحظي بالذكاء الاصطناعي**: فور كتابة 3 كلمات فأكثر، يبحث المحرك الدلالي في بنك الأفكار ويظهر تنبيهاً بنسب التطابق لتفادي تكرار الأفكار.
   - **إدخال صوتي (Voice Dictation)**: إمكانية تسجيل الفكرة والتحدث بالصوت باللغتين العربية أو الإنجليزية مع تفريغ نصي لحظي.
   - **تصنيف وتلخيص آلي**: تصنيف الفكرة تلقائياً وتوليد وسوم ذكية وملخص تنفيذي.

4. **المشاركة والتصويت المجتمعي (Community & Gamification)**:
   - تصويت إيجابي وسلبي، تعليقات وردود ونظام إعجاب.
   - لوحة شرف المبتكرين (Leaderboard) ونقاط وأوسمة التميز.

5. **لوحة المؤشرات والتحليلات (Interactive Analytics Dashboard)**:
   - مؤشرات بيانية لتوزيع الأفكار حسب الإدارات والمحاكم.
   - رسوم بيانية لحالات الاعتماد والدراسة والرفض.
   - إمكانية تصدير التقرير الفوري بصيغة CSV.

6. **لوحة تحكم المشرف (Admin Console)**:
   - إضافة وحذف الإدارات والمحاكم، المسميات الوظيفية، وفئات الابتكار مع الانعكاس الفوري في جميع القوائم.
   - إعدادات مفتاح Google Gemini API للذكاء الاصطناعي السحابي أو الاعتماد على المحرك المدمج.

## 🌐 رفع المشروع إلى GitHub ونشره / Deploy to GitHub & GitHub Pages

### 1. تهيئة المستودع وإجراء أول Commit:
```bash
git init
git add .
git commit -m "Initial commit: Fikra - SJC Qatar Innovation Platform"
```

### 2. ربط المستودع بـ GitHub:
```bash
# قم بإنشاء مستودع جديد على حسابك في GitHub باسم SJC-Fikra
git branch -M main
git remote add origin https://github.com/<YOUR_USERNAME>/SJC-Fikra.git
git push -u origin main
```

### 3. التفعيل التلقائي لـ GitHub Pages:
- انتقل إلى مستودعك على GitHub.
- ادخل إلى **Settings** > **Pages**.
- في قسم **Build and deployment** اختر **Source: GitHub Actions**.
- سيتولى ملف `.github/workflows/deploy.yml` بناء ونشر الموقع تلقائياً على الرابط:
  `https://<YOUR_USERNAME>.github.io/SJC-Fikra/`
